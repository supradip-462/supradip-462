## `>_` About Me

I am **Supradip Bhattacharjee**, a **Cyber Security Student** focused on understanding how systems break—and how to engineer stronger defenses against modern threats. 

My work sits at the intersection of **defensive security tooling**, **offensive security concepts**, and **application development**. Rather than relying purely on theory, I build hands-on security utilities—ranging from vulnerability scanners and password strength analyzers to phishing detection models—to explore how attackers operate and how automation can mitigate risk.

- **Current Focus:** Deepening my practical knowledge in Penetration Testing, Vulnerability Assessment, Network Security, and Python-based security automation.
- **Development Approach:** Combining scripting and full-stack web technologies to turn security concepts into usable tools.
- **Mindset:** Committed to continuous learning, ethical research, and writing clean, maintainable code.
